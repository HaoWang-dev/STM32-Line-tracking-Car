# STM32-Line-tracking-Car
本项目为基于 STM32 的智能循迹避障小车。系统以 STM32 为主控，具备循迹和避障功能。循迹部分采用作者自创的 PID 循迹算法，根据传感器偏差实时调节电机输出，实现轨迹跟踪。
本项目的循迹模块采用感为科技带 MCU 的八路灰度循迹传感器，姿态检测使用维特智能 JY61P 姿态传感器，障碍物检测则采用检测距离可调节的光电传感器。上述所有传感器的驱动代码均进行了独立封装，各传感器驱动模块之间耦合度较低、接口清晰，便于在不同项目之间直接移植和复用。
项目的 PCB 采用嘉立创 EDA 设计，相关原理图与工程文件均存放于 PCB 文件夹中，便于查阅和后续修改。
本项目基于 STM32Cube 生态进行开发。开发过程中，使用 STM32CubeMX 完成 MCU 外设配置与初始化代码框架生成，并在 STM32CubeIDE 中编写和调试各模块驱动代码。项目已提供完整工程文件，可直接使用 STM32CubeIDE 打开，无需额外搭建工程环境，便于快速编译、下载与调试。
该项目为作者大一阶段自主设计完成，仍存在参数整定、鲁棒性和复杂路况适应性等方面的改进空间。如有不足之处，欢迎指正。
