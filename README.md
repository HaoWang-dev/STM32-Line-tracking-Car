# STM32-Line-tracking-Car
本项目为基于 STM32 的智能循迹避障小车。系统以 STM32 为主控，具备循迹和避障功能。循迹部分采用作者自创的 PID 循迹算法，根据传感器偏差实时调节电机输出，实现轨迹跟踪。该算法为作者大一阶段自主设计，仍存在参数整定、鲁棒性和复杂路况适应性等方面的改进空间。如有不足之处，欢迎指正。
循迹模块使用的是感为科技的带MCU的八路灰度循迹

姿态传感器使用维特智能的JY61P，障碍检测使用可调节的光电传感器。所有传感器驱动代码均单独封装，方便在不同项目之间进行移植。
项目的 PCB 采用嘉立创 EDA 设计，相关原理图与工程文件均存放于 PCB 文件夹中，便于查阅和后续修改。
